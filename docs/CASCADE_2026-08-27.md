## 3f. **IS THE BOOK EMPTY? NO. CONFIRMED.**

§6.7 sizes between **GBP 1,875** (a 40% stop) and **GBP 15,000** (a 5% stop),
being `GBP 750 / stop_distance`.

**The derived US floor at the calibration share price is USD 6,055 = GBP 4,694**
at 1.29 USD/GBP.

```
GBP 1,875  <=  GBP 4,694  <=  GBP 15,000        INSIDE the band
```

***And no FX assumption is load-bearing.*** The floor stays inside §6.7's band
for **any** USD/GBP rate between **0.404 and 3.229**. The rate used is nowhere
near either bound, so the conclusion survives row 1's open FX question entirely.

**What that means concretely.** A position reaches the floor whenever the stop
is tight enough:

```
position = GBP 750 / stop  >=  GBP 4,694    <=>    stop <= 15.98%
                                            <=>    ATR at h=5 <= 6.39%
```

**So positions exist, for stops up to about 16%, which is the lower two fifths
of §6.7's 5% to 40% range.** **The design is coherent and the book is not
empty.**

*The honest counterpart:* stops wider than ~16% produce positions **below** the
floor, which are killed by `position_below_clip_floor`. **The floor bites, and a
floor that never bit would not be a floor.**
