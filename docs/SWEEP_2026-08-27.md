## 6b. The sweep. ***It does not run.***

```
$ python -m fntn.scanner sweep
no API key: set ANTHROPIC_API_KEY or pass api_key. Refusing rather than falling
back to an unauthenticated call that would fail later with a less useful message.
```

**`ANTHROPIC_API_KEY` is unset and no transcript exists for these corpora.**
`AnthropicClient` refuses at construction, which is where it is designed to
refuse: *"both are checked at construction rather than at first call, so a
misconfiguration surfaces before a sweep is half-run."*

### What was NOT done, and why each was refused

***Nothing was substituted, and the temptations are named because they were
real.***

| Substitute | Why it was refused |
|---|---|
| **Author the proposals directly**, this session's model being a model | ***That is AUTHORED material presented as a DRAWN sweep***, and it is the exact defect class P77, P79 and P95 corrected three times. §13 rows 21 and 23 were each re-based for pooling an authored arm with a drawn one; **manufacturing an authored arm and calling it the drawn one is the same error committed on purpose** |
| **Write a transcript and replay it** through `TranscriptClient` | The same thing wearing the replay mechanism. *`TranscriptClient` replays **a payload a model produced**; a payload this session wrote is not a replay of anything* |
| Fall back to an unauthenticated call | The client already refuses this, in those words, and it is right to |

**CLAUDE.md rule 3: refuse to score, never fall back to a default.** *A sweep
that produced proposals by any of the three routes above would have produced a
list, and the list would have been evidence of nothing except that the
apparatus can be talked into running.*

### The control arm cannot run either, and the reason is structural rather than incidental

`draw_control_mechanisms` is **a seeded uniform draw over the grid and needs no
model at all**, so it looked as though it could run alone.

***It cannot, and the reason is a design property worth stating.*** `run.py`
sizes the control arm as

```python
max(1, round(len(proposals) * config.control_arm_ratio)) if proposals else 0
```

**The control arm's size is defined RELATIVE to the agent arm**, at the
registered ratio of 1.0, because **it exists to be compared against it at
matched *n*.** With zero agent proposals the correct control arm is **zero**.

*A control arm drawn without a treatment arm to match would be a list of random
mechanisms with nothing to be a control for.* **The machinery declining to
produce one is the ratio doing its job.**
