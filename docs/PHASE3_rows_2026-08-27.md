## 3b. Row 15, ingestion-lag threshold: **stays BLOCKED**

**No lag was observed, because no lag was observable.** The rule requires the
*observed lag distribution per source class*, which is the interval between a
source publishing and the system ingesting. **The trace corpus carries no
publication timestamps and the harness records no ingestion timestamps against
them**, so the quantity has not been measured once, at any n.

**On whether one source class dominates: it does not, and that is not good
news.** The 36 drawn subjects are **12 ASX, 12 TSX/SEDI, 12 Frankfurt/Euronext
MAR**, an even three-way split. **The US class has zero drawn subjects.** So
the sample is balanced across three classes **none of which is the primary
catalyst family's own flow**, and generalising a lag threshold from them to SEC
Form 4 would be generalising across exactly the classes the sample does not
cover. **No threshold is proposed and none is derivable.**

**What unblocks it:** a fetched filing flow carrying publication timestamps,
which is phase 2, which is refused.

## 3c. Row 11, audit-stream minimum n (§7.2): **stays BLOCKED, and names the input**

**The derivation is shown so that what is missing from it is visible.**

For a per-gate difference between two arms of a binomial outcome, at size α and
power 1−β, the standard two-proportion sample size per arm is

```
n  =  (z[1-α/2] + z[1-β])²  ·  2·p̄·(1-p̄)  /  δ²
```

**What is observable:**

```
z at α = 0.05 two-sided, power 0.80    →  (1.95996 + 0.84162)² = 7.8489
p̄, the observed intake kill rate       →  8/36 = 0.2222   (drawn arm, §3a)
2·p̄·(1-p̄)                              →  0.3457
so  n  =  2.7132 / δ²
```

**What is NOT observable, and it is the numerator of the whole exercise: δ,
"the smallest actionable per-gate difference".** It appears in row 11's rule
and **nowhere else in the specification**. It has no definition, no §13 row of
its own and no stated basis. **A sample size derived against an undefined δ
would be a number chosen and presented as derived**, which is the failure
CLAUDE.md's fifth rule exists against.

**So the row stays BLOCKED, and the input it names is δ.** The sensitivity is
tabulated so the operator can see what choosing δ costs, **without this file
choosing it**:

| δ, the smallest actionable per-gate difference | n per arm | Funnel throughput at a 10% audit stream |
|---|---|---|
| 20 pp | 68 | 680 |
| 15 pp | 121 | 1,210 |
| 10 pp | 272 | 2,720 |
| 5 pp | 1,086 | 10,860 |
| 2 pp | 6,783 | 67,830 |
| 1 pp | 27,132 | 271,320 |

**Two honest limits on even this arithmetic.** First, **p̄ = 0.2222 is an
intake kill rate standing in for a per-gate rate**, taken over 36 proposals
from three non-US corpora; §7.2's audit stream measures gates, not intake, and
no gate has ever run. Second, the table assumes one comparison; §6.4's four
counting families mean a per-gate attribution is many comparisons, and nothing
here carries a multiplicity correction. **Both push n up, neither is applied,
and the table is therefore a floor on a floor.**

## 3e. Binding-path step 4: **NOT DISCHARGED**

**The stopping rule, quoted from §9.4:**

> **The harness carries a pre-registered stopping rule.** It runs in blocks;
> after each, the marginal defect rate per hundred items is computed; when that
> falls below a stated threshold for two consecutive blocks, tracing stops, the
> register closes, and the parameter object is hashed.

**And §14's precondition, quoted:**

> §9.4's harness run to its pre-registered stopping rule, across a stated count
> of items spanning source classes and catalyst types, **including a minimum
> sample of the primary catalyst family's live filing flow**. Resulting defects
> are freeze-blocking.

**Exactly what remains, each item independent of the others:**

1. **The live filing flow does not exist.** Phase 2 refused for want of
   `SEC_CONTACT`. The corpus at `corpora/_trace_filings/` is empty. This alone
   fails the precondition's final clause.
2. **No block has been run.** A block is one hundred items; the trace to date
   is 42 subjects, of which 6 are authored probes. **42 is not a block.**
3. **Two consecutive blocks are required**, so **200 items is the arithmetic
   minimum** even once fetching works.
4. **The threshold the marginal defect rate must fall below is not stated.**
   §9.4 says *"a stated threshold"* and **the specification does not state it,
   and it has no §13 row.** *A stopping rule whose threshold is unstated cannot
   be discharged by any amount of tracing*, and this is a defect in the rule
   rather than a shortfall in the work. It is the item most likely to be
   overlooked, because the other three look like effort and this one looks like
   a detail.
5. **The count of items and the span of source classes and catalyst types is
   "stated" nowhere.** The precondition requires *a stated count*; no count is
   stated.

**Step 4 is not marked closed, and the report's movement line will not show it
moving.** Items 4 and 5 are decisions for the operator and are carried into
`docs/DECISION_PACK.md`; items 1 to 3 are work that unblocks the moment
`SEC_CONTACT` is set.
