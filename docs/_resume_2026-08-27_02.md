  `SEC_CONTACT` and `ANTHROPIC_API_KEY`. **Both are now content-checked**, so

**But `master.py`'s `load_csv` carried this:**

```python
row_market = (row.get(mkt_col) or "").strip() or default_market
```

**`default_market` is the FILE STEM where the operator names no market**, and
`cli.py` passes `market=None` for any spec written without a `:MARKET` suffix,
so ***the path is live and reachable, checked rather than assumed.*** A row
with a blank exchange cell was **counted into a market that never claimed it**,
and `coverage = rows / listed_total` rose accordingly.

***The rule it broke is stated eight lines above the line that broke it***, in a
comment about an earlier version that collapsed markets and produced a figure
which "looks like a measurement", which is worse than no figure. **That is
exactly Class V's shape: a rule written in prose and a weaker predicate
beneath it**, and it is the fifth instance, found by the sweep the invariant
itself mandates, one commit after installation.

**Repaired**: unattributable rows go to a bucket of their own, whose
`listed_total` is `None`, so its coverage reads **unknown** and cannot pass a
floor it was never measured against. ***The fence is unweakened***: names and
tickers index globally, so every issuer in the file still binds; what changed
is only which market may CLAIM the row. **The test fails against the old line
and passes against the new one**, verified by restoring the defect.
